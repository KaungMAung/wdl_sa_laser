# SA-005 — Verify operation state and scan workflow API

Status: DONE
Type: API

## Purpose

Verify that API operation routes delegate to `RunService` and return authoritative state for scanner actions.

## Current Evidence

`api/recipe_api.py` routes operation actions to backend context; `services/run_service.py::RunService` owns lot and scan rules.

## Scope

Test state retrieval, PO/run scan, inspection lot, inspection point, serial scan, validation errors, and state snapshots using fake SQL/PLC services.

## Out of Scope

No GUI scanner focus testing, live PLC, or SQL Server.

## Acceptance Criteria

- [API] Valid actions advance the expected per-lot state and response contains the authoritative snapshot.
- [API] Invalid/duplicate serials are rejected by backend rules and do not mutate state.
- [API] Four lots remain independent in returned state.

## Verification Required

Use API requests against a controlled backend and compare database/state snapshots before and after each action.

## Dependencies

SA-001, SA-003

## Notes / Constraints

Inspection Point behavior is current implementation: it is validated as the first serial; do not reinterpret it in this task.

## Implementation Summary

Added HTTP-boundary operation tests using the existing `RunService`, temporary
SQLite inspection storage, and fake SQL/PLC/recipe services. The tests cover
authoritative operation state, Run/PO lookup, Inspection Lot, Inspection Point
as first serial, valid serial scanning, duplicate rejection, and invalid serial
rejection. No production operation logic was changed.

## Verification Evidence

- [API] `python -m unittest discover -s tests -v`
  - Result: 13 tests passed, 0 failures, 0 errors.
- [AUTO] `python -m compileall -q api api_main.py services tests`
  - Result: exit code 0.
- [API] `/api/operation/state` returned four lot snapshots plus SQL/PLC status.
- [API] Scan requests advanced the backend-owned lot state and returned the
  expected scan counts.
- [API] Duplicate and unknown serial scans returned HTTP 400 and did not add
  another scanned serial.
