# SA-032 — Close Recipe.xlsx workbook handles after import

Status: READY
Type: BUG

## Purpose

Review and correct workbook resource lifetime so Windows does not retain a file
lock after recipe import.

## Current Evidence

SA-020’s temporary workbook required garbage collection before Windows could
remove the file. `services/recipe_service.py::import_workbook` loads a
read-only openpyxl workbook without an explicit close.

## Scope

Define deterministic workbook close behavior and regression coverage on Windows.

## Out of Scope

No recipe mapping semantics or PLC behavior changes.

## Acceptance Criteria

- [AUTO] Import leaves the workbook removable/replaceable on supported Windows
  environments.
- [AUTO] Import behavior and counters remain unchanged.

## Verification Required

Run the importer fixture without forced garbage collection and remove/replace
the workbook before cleanup.

## Dependencies

SA-020

## Notes / Constraints

Do not change recipe mapping semantics or PLC behavior.
