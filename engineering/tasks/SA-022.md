# SA-022 — Characterize SQL lookup database-name configuration defect

Status: DONE
Type: BUG

## Purpose

Verify whether the PO lookup query incorrectly hard-codes a database name instead of using configured database settings.

## Current Evidence

`services/database_service.py::lookup_po` contains a three-part table reference using `[workflow-u-woodlands-sg-new]`; config also defines a database value.

## Scope

Compare configured database values with generated SQL and safe fake-cursor execution; document impact and required correction.

## Out of Scope

No SQL query or configuration change.

## Acceptance Criteria

- [AUTO] A test captures the generated query and proves whether configuration changes the database target.
- [CODE] A separate implementation requirement is recorded if hard-coding is confirmed.

## Verification Required
