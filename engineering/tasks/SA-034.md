# SA-034 — Use configured database name in PO lookup

Status: READY
Type: BUG

## Purpose

Correct the PO lookup query so its database target follows persistent
configuration while retaining parameterized PO filtering.

## Current Evidence

SA-022 captured `DatabaseService.RUN_LOOKUP_SQL` and confirmed it references
`[workflow-u-woodlands-sg-new]` even when `DatabaseConfig.database` is another
value.

## Scope

Use the configured database context as the query authority and update
verification coverage without weakening parameterization.

## Out of Scope

No production SQL Server execution or schema/data changes.

## Acceptance Criteria

- [AUTO] Generated lookup target follows configured database safely.
- [AUTO] PO input remains a bound parameter.
- [AUTO] Offline query-capture coverage verifies the configured database target
  without weakening parameterization.

## Verification Required

Extend SA-022 fake-cursor coverage. Controlled/live SQL Server verification is
owned separately by SA-012 and is not a dependency for this correction.

## Dependencies
