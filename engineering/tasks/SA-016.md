# SA-016 — Verify live PLC status/result polling persistence

Status: ALIGNING
Type: PLC

## Purpose

Verify real PLC Result/Status polling, changed-disc persistence, and UI/API visibility.

## Current Evidence

`services/backend_poller.py` polls every two seconds after load and routes changes to `RunService`; `InspectionStore` persists changed values.

## Scope

Change Result/Status for selected physical parts, observe mapped API state, Current updates, and events; verify unchanged parts are not rewritten.

## Out of Scope

No PLC tag redesign or status/result mapping changes.

## Acceptance Criteria

- [PLC] Polling observes configured raw integers and mapped text.
- [DB] Only changed discs receive Current updates/events.
- [API] Operation state reflects the changed disc without a full GUI reload.
- [HUMAN] Engineer confirms observed machine/PLC behavior.

## Verification Required

Use timestamped PLC manipulation and correlate backend logs, API snapshots, and SQLite rows.

## Dependencies

SA-007, SA-015

## Notes / Constraints

Polling interval and mapping are configuration concerns; preserve raw values.
