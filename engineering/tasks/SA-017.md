# SA-017 — Verify PLC identity mismatch protection

Status: ALIGNING
Type: PLC

## Purpose

Verify locked identity fields are not overwritten when PLC reports a different serial/material/lot/tray/part identity.

## Current Evidence

`services/run_service.py` and `services/inspection_store.py` contain identity checks and `IDENTITY_MISMATCH` event handling.

## Scope

Induce mismatches for each protected identity dimension, observe error/event state, and restore matching identity to verify recovery.

## Out of Scope

No identity policy redesign or PLC write changes.

## Acceptance Criteria

- [PLC] Mismatched identity is detected and reported for the affected disc.
- [DB] Current identity fields remain unchanged and status/result updates are suspended for the mismatch.
- [DB] Matching identity permits polling to resume according to current behavior.

## Verification Required

Correlate PLC values, API state, Current rows, and `IDENTITY_MISMATCH` events.

## Dependencies

SA-016

## Notes / Constraints

The exact machine procedure for inducing a mismatch requires PLC-owner approval.
